# 我想记

一款面向 Android 9.0 的无广告记账 App，主打多账本管理、快速记账、月度统计和本地数据安全。

## 亮点

- 无广告、离线可用
- 多账本管理，适合不同生活场景
- 支持收入、支出、转账、余额调整
- 金额支持基础运算输入
- 月度维度查询与图表统计
- 本地备份、恢复与 CSV 导出

## 核心功能

### 首页

- 当前账本与总结余展示
- 最近账单时间线
- 当月收入、支出、结余概览

### 账单

- 按月查看账单
- 支持筛选、搜索、编辑、删除
- 时间线式账单展示

### 统计

- 月度收入、支出、结余汇总
- 日趋势图
- 收支分类占比图

### 记账

- 账单类型：收入、支出、转账、余额调整
- 记账要素：类别、日期、金额、备注
- 类别宫格选择
- 备注弹窗录入
- 模拟键盘快速输入金额

### 管理

- 账本管理
- 账户管理
- 分类管理
- 数据备份与恢复

## 技术栈

- Kotlin
- Android View + XML
- ViewBinding
- SQLite
- Material Design

## 运行环境

- Android 9.0+（`minSdk 28`）
- `compileSdk 36`

## 本地构建

```bash
./gradlew assembleDebug
```
